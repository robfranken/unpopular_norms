The emergence of an unpopular norm in a social network experiment
===========================================

This repository contains code and data accompanying the paper “The emergence of an unpopular norm in a social network experiment.” 

## Replication materials

The repository includes R-scripts for:

- Simulation and analysis of an **agent-based model**
- Reproducing figures and analysis based on **experiment** data.

The scripts and accompanying documentation are presented on our [replication website](http://robfranken.github.io/unpopular_norms/).

## Experimental software

The repository also contains the **oTree code (v.5.10.4)** used to conduct the study, including:

1. `sign-up-survey`: the survey used to register participants for an experimental session.
2. `coordination-experiment`: the application used to conduct the experiment.
